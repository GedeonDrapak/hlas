Diktování česky na Windows

Hlas pro Windows 10 a 11 je v betě. Umí lokální model Whisper i vlastní API klíč, Hlas Cloud zatím ne, a instalátor ještě není podepsaný.

Proč Windows varuje před instalátorem?

Instalátor zatím nemá podpis kódu, proto SmartScreen ukáže varování. Klikněte na Další informace a Přesto spustit. Podpis přidáme před veřejným startem.

Co na Windows funguje?

Diktování klávesovou zkratkou do jakékoli aplikace, lokální model Whisper, vlastní klíče Groq a OpenAI, slovník a historie. Aplikace je nativní, napsaná v Rustu.

Funguje na Windows Hlas Cloud?

Ano, od verze 0.6.0. V Nastavení na stránce Hlas Cloud spustíte 7denní zkoušku zdarma nebo vložíte licenční klíč. Jedna licence platí až na 5 počítačích.
