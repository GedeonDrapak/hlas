Hlas / Dictation for smaller languages

Dictation for smaller languages

Hlas was built in Prague for Czech, a language big dictation apps treat as an afterthought. Czech, Slovak and English have extra tuning; every other language below runs on Whisper large-v3 as is.

Which languages does Hlas support?

More than 60, everything Whisper large-v3 can transcribe. Each language below has its own page written natively, not machine-switched.

Why are only three languages tuned?

Tuning means a priming prompt and tests with native speakers, and we only ship it where we can check the result ourselves. If you speak one of these languages, tell us on GitHub how Hlas does and which words it gets wrong.
