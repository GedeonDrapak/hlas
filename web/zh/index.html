常见问题

你可能想问的。

免费版真的免费吗？

是的。本地引擎在你的电脑上运行，不花一分钱。如果你更想用云端引擎，可以填入自己的 API 密钥，直接向服务商付费，通常每月一到三美元。

Hlas 能离线使用吗？

可以。使用本地引擎时，Whisper 在你的 Mac 上运行，只需一次性下载 547 MB 的模型，之后无需联网。

中文识别效果怎么样？

Hlas 使用支持中文的 Whisper large-v3。识别质量会因语言、说话方式和口音而不同，建议先用免费版试试。把人名和术语加进词库，Hlas 就会按你的写法输出。

听写时占用多少内存？

空闲时约 60 MB。本地模型加载期间约 1 GB，静默 3 分钟后释放。Hlas Cloud 完全不加载模型。

支持 Intel 芯片的 Mac 吗？

不支持。Mac 版需要 Apple Silicon 和 macOS 15 或更高版本。x64 的 Windows 10 和 11 以测试版形式支持。

能用语音给 Claude Code、Cursor 或 ChatGPT 输入提示词吗？

可以。只要能打字的应用，Hlas 都能输入，包括终端和代码编辑器。把库名和函数名加进词库，就能写得准确。

发票和取消订阅怎么处理？

付款后，Stripe 会通过邮件发送 Eden Makers s.r.o. 开具的增值税发票。欧盟企业可在结账时填写增值税号。更换银行卡、下载发票或取消订阅都在客户门户里完成，取消后订阅会持续到已付费年度结束。

无限到底有多无限？

Hlas Cloud 没有分钟计数，也没有档位。为了让价格保持在每年 €35，合理使用上限为每天 3 小时语音输入，在 UTC 零点重置。

我的语音会发到哪里？

使用本地引擎时，哪里也不去，始终留在你的电脑上。使用 Hlas Cloud 时，语音经由我们的服务器发送给 Groq，仅用于转写，我们的服务器不会保存。使用自己的密钥时，语音直接发送给你选择的服务商。
