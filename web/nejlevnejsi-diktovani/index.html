Časté otázky

Jaká je nejlevnější aplikace na diktování?

Úplně zdarma je lokální diktování: Hlas (Mac a Windows) přepisuje přes Whisper přímo v počítači bez limitu a bez účtu. Nejlevnější neomezené předplatné bez API klíčů je Hlas Cloud za 35 € ročně. Z jednorázových licencí je nejlevnější VoiceInk za 25 $.

Jde diktovat česky zdarma?

Ano. Hlas je zdarma a čeština v něm má vlastní ladění: primovací prompty, slovník, mluvené symboly a zalomení řádků. Lokální model funguje i bez internetu.

Kolik stojí přepis přes vlastní API klíč?

Groq účtuje model whisper-large-v3-turbo asi 0,04 $ za hodinu zvuku. Hodina diktování denně tak vyjde zhruba na 1,20 $ měsíčně. Hlas vlastní klíč Groq i OpenAI podporuje zdarma.

Proč je Hlas Cloud tak levný?

Hlas je malá nativní aplikace bez vlastní infrastruktury navíc: zvuk jde přes náš server na Cloudflare rovnou ke Groq. Nic neukládáme a neplatíme za drahé vlastní modely, takže cena může zůstat nízko.
