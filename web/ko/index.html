자주 묻는 질문

궁금한 점, 미리 답해 드려요.

무료 버전은 정말 무료인가요?

네. 로컬 엔진은 내 컴퓨터에서 돌아가서 비용이 전혀 들지 않아요. 클라우드 엔진을 원하면 내 API 키를 연결하고 제공업체에 직접 내면 돼요. 보통 한 달에 1에서 3달러 정도예요.

오프라인에서도 되나요?

네. 로컬 엔진을 쓰면 Whisper가 맥에서 바로 돌아가서, 547 MB 모델을 한 번 내려받은 뒤에는 인터넷이 필요 없어요.

한국어는 얼마나 잘 알아듣나요?

Hlas는 한국어를 지원하는 Whisper large-v3를 써요. 인식 품질은 언어와 말투, 억양에 따라 달라지니 무료 버전으로 먼저 써 보세요. 이름과 용어를 단어장에 넣으면 원하는 대로 써요.

받아쓰는 동안 메모리는 얼마나 쓰나요?

대기 중에는 약 60 MB예요. 로컬 모델을 불러온 동안에는 약 1 GB를 쓰고, 3분 동안 조용하면 내려놓아요. Hlas Cloud는 모델을 아예 불러오지 않아요.

인텔 맥에서도 되나요?

아니요. 맥 앱은 Apple Silicon과 macOS 15 이상이 필요해요. x64 Windows 10, 11은 베타로 지원해요.

Claude Code, Cursor, ChatGPT에 프롬프트를 말로 입력할 수 있나요?

네. Hlas는 타이핑할 수 있는 모든 앱에 입력해요. 터미널과 코드 에디터도 마찬가지예요. 라이브러리와 함수 이름을 단어장에 넣어 두면 정확하게 나와요.

인보이스와 해지는 어떻게 하나요?

결제 후 Stripe가 Eden Makers s.r.o. 명의의 VAT 인보이스를 이메일로 보내 드려요. EU 사업자는 결제할 때 VAT 번호를 입력할 수 있어요. 카드 변경, 인보이스 다운로드, 해지는 고객 포털에서 하시면 되고, 해지해도 결제한 1년이 끝날 때까지 쓸 수 있어요.

무제한이면 정말 무제한인가요?

Hlas Cloud에는 분 단위 카운터도, 요금 등급도 없어요. 연 €35를 유지하기 위해 공정 사용 기준으로 하루 3시간까지 받아쓸 수 있고, UTC 자정에 초기화돼요.

내 음성은 어디로 가나요?

로컬 엔진이라면 아무 데도 가지 않고 내 컴퓨터에 남아요. Hlas Cloud에서는 받아쓰기를 위해서만 저희 서버를 거쳐 Groq로 가고, 저희 서버에는 저장되지 않아요. 내 키를 쓰면 고른 제공업체로 바로 가요.

타이핑은 그만. 이제 말하세요.
