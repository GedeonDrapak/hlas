Hlas / Soukromí

Soukromí

Hlas má dvě vrstvy: lokální režim, ve kterém zvuk nikdy neopustí počítač, a Hlas Cloud, ve kterém se zvuk přepisuje u Groq a nikde se neukládá. Toto je srozumitelné shrnutí, plné zásady a obchodní podmínky připravujeme s právníkem.

Co Hlas posílá z počítače v lokálním režimu?

Nic. Přepis běží přes whisper.cpp přímo v počítači, bez účtu a bez telemetrie. Jedinou síťovou akcí je jednorázové stažení modelu a kontrola aktualizací přes Sparkle, na kterou se aplikace jednou zeptá.

Co se děje s vlastním API klíčem?

Zvuk jde přímo k poskytovateli, kterého jste vybrali (Groq, OpenAI, Soniox nebo Fish Audio), a řídí se jeho podmínkami. Klíč je uložený v systémové klíčence a přes naše servery nejde.

Co se děje s Hlas Cloud?

Zvuk jde z aplikace přes náš server na Cloudflare ke Groq, který ho přepíše a vrátí text. Náš server zvuk ani text neukládá. Ukládáme jen to, co je nutné pro předplatné: identifikátor zákazníka ve Stripe, e-mail, šifrovaný licenční klíč a počet sekund zvuku za den kvůli férovému užívání.

Měříte návštěvnost?

Jen anonymně. Když na webu klikneš na stažení nebo předplatné, server přičte jedničku k počítadlu tlačítka a jazyka stránky. Neukládáme IP adresu, cookie ani žádný identifikátor. U zkušební verze Hlas Cloud si aplikace vytvoří náhodné ID instalace, aby šla zkouška spustit jen jednou; ukládáme z něj jen otisk (hash). Stejný otisk slouží k limitu 5 počítačů na jedno předplatné.

Používá web cookies?

Ne. Web nepoužívá analytiku s cookies ani sledovací skripty. Platební stránka Stripe má vlastní podmínky.
