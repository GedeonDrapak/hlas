คำถาม

ก่อนคุณจะถาม

เวอร์ชันฟรีฟรีจริงไหม

ฟรีจริง เอนจินโลคัลทำงานบนเครื่องของคุณและไม่มีค่าใช้จ่าย ถ้าอยากใช้เอนจินบนคลาวด์ ก็ใส่ API key ของคุณเองแล้วจ่ายให้ผู้ให้บริการโดยตรง ปกติเดือนละหนึ่งถึงสามดอลลาร์

Hlas ใช้ออฟไลน์ได้ไหม

ได้ เมื่อใช้เอนจินโลคัล Whisper จะทำงานบน Mac ของคุณ และไม่ต้องใช้อินเทอร์เน็ตหลังดาวน์โหลดโมเดล 547 MB ครั้งแรก

เข้าใจภาษาไทยได้ดีแค่ไหน

Hlas ใช้ Whisper large-v3 ซึ่งรองรับภาษาไทย คุณภาพแตกต่างกันไปตามภาษาและสำเนียง ลองใช้เวอร์ชันฟรีดูก่อน และเพิ่มชื่อกับศัพท์เฉพาะลงในคลังคำ Hlas จะเขียนตามแบบของคุณ

ใช้ RAM เท่าไหร่ขณะพูด

ขณะว่างประมาณ 60 MB ระหว่างโหลดโมเดลโลคัลใช้ประมาณ 1 GB และจะปล่อยออกหลังเงียบไป 3 นาที Hlas Cloud ไม่โหลดโมเดลเลย

ใช้กับ Mac ชิป Intel ได้ไหม

ไม่ได้ แอป Mac ต้องใช้ Apple Silicon และ macOS 15 ขึ้นไป ส่วน Windows 10 และ 11 บน x64 รองรับในช่วงเบต้า

พูดพรอมต์ลงใน Claude Code, Cursor หรือ ChatGPT ได้ไหม

ได้ Hlas พิมพ์ได้ทุกแอปที่พิมพ์ได้ รวมถึงเทอร์มินัลและโปรแกรมแก้โค้ด เพิ่มชื่อไลบรารีและฟังก์ชันลงในคลังคำเพื่อให้สะกดถูก

ใบแจ้งหนี้และการยกเลิกทำอย่างไร

หลังชำระเงิน Stripe จะส่งใบกำกับภาษี VAT จาก Eden Makers s.r.o. ทางอีเมล บริษัทใน EU ใส่เลข VAT ได้ตอนชำระเงิน เปลี่ยนบัตร ดาวน์โหลดใบแจ้งหนี้ หรือยกเลิกได้ในพอร์ทัลลูกค้า แล้วการสมัครจะใช้ได้จนครบปีที่จ่ายไว้

ไม่จำกัดแค่ไหน

Hlas Cloud ไม่มีตัวนับนาทีหรือแบ่งระดับแพ็กเกจ เพื่อให้ราคาอยู่ที่ปีละ €35 การใช้งานอย่างเป็นธรรมคือไม่เกิน 3 ชั่วโมงต่อวัน และรีเซ็ตตอนเที่ยงคืน UTC

เสียงของฉันไปอยู่ที่ไหน

ถ้าใช้เอนจินโลคัล ไม่ไปไหน อยู่ในเครื่องของคุณ ถ้าใช้ Hlas Cloud เสียงจะผ่านเซิร์ฟเวอร์ของเราไปยัง Groq เพื่อถอดความเท่านั้น และเซิร์ฟเวอร์ของเราไม่เก็บไว้ ถ้าใช้คีย์ของคุณเอง เสียงจะส่งตรงไปยังผู้ให้บริการที่คุณเลือก
